# Условие
# Структура проекта
- `src/` - исходный код основной программы
- `tests/` - unit-тесты с использованием Google Test
- `include/` - заголовочные файлы
- `CMakeLists.txt` - конфигурация CMake

#  Сборка и запуск
```bash
# Создание директории для сборки
mkdir build
cd build

# Конфигурация CMake
cmake ..

# Сборка проекта
make

# Запуск основной программы
./main

# Запуск тестов
./tests
